# Python 练习

Python 基础练习代码。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `day01.py` | 基础语法练习（成绩判断、循环、九九乘法表）以及学生管理系统练习 |
| `day02.py` | 读取 `student.txt`，按逗号切分并逐行打印 |
| `student.txt` | 学生成绩测试数据（姓名, python, 英语, 数学） |

## 运行

```bash
python day01.py
python day02.py
```

> 注意：`day02.py` 与 `day01.py` 中的文件读取依赖当前目录下的 `student.txt`，请在 `python-practice` 目录下运行。
